# Datos de «La historia del día» que sí van al repositorio

- `hoy_formulario.html`: pega aquí el código del formulario incrustado del servicio de correo, cuando lo tengas.
  Vacío = no se muestra el formulario.
- `hoy_enlaces.csv`: enlaces de Amazon Attribution por libro (opcional). Vacío = botón a la ficha del catálogo.
- `hoy_privacidad.md`: el texto de la página `/privacidad/`. Es un **borrador** para que lo revise el autor: mientras
  empiece por «BORRADOR» o tenga datos por poner (`[[…]]`), el formulario de correo no se publica.
